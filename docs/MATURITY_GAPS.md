## 本轮已修与证据

- DSHarness 在累计超过 8,388,608 个 UTF-16 代码单元时立即拒绝，不再等待整行结束才检查；不是“所有缓存总共只用 8 MB”的承诺。
- 队列生产者加入取消信号，退出时取消并有限等待读取任务。该改动不新增依赖或修改用户数据格式。
- 读取器 7 个断言通过：空行、中文、LF/CRLF/CR、恰好上限、无末尾换行、EOF、无界输入的提前拒绝。
- 桥接器夹具通过正常两轮对话及超长无换行、确认前事件洪泛、坏 JSON、输出管道关闭 4 类故障。旧候选对相同无换行夹具在 20 秒仍未结束；新候选能安全报错结束。
- 测试启动器显式构造 Windows 环境块，处理测试环境同时携带 Path/PATH 的情况；不声称已修复所有外部启动器的环境问题。
- README 更新为真实的只读 PDF/Office 预览能力；打包清单补齐最新验证记录和本清单，加入文档相对链接回归。
- 新测试已接入 CI 配置；远程执行结果尚待验证。此次未调用付费模型，未覆盖已安装程序，未推送或发布远程仓库。

更多既有证据见 [验证状态](VALIDATION_STATUS.md)、[6.4.24 本机验收](VALIDATION_6.4.24.md) 与 [预览取消修复](VALIDATION_PREVIEW_CANCELLATION.md)。
