## 明确边界

- Windows EXE 尚无商业 Authenticode 签名，系统可能显示未知发布者；发布页必须提供 SHA-256。
- 当前主要验证环境是 Windows 11 x64 与 Evergreen WebView2。干净 Win10/Win11、真实中文用户名、非管理员账户、物理无 D 盘和更多历史数据升级组合仍需继续扩充。
- Claude、Codex、DSHarness、Pi 的真实 CLI 路径已验证；第三方付费云端 Provider、中转服务和未来 CLI 版本仍可能需要适配。
- Office 预览是简化只读预览，不等同完整 Office 编辑器。
- 静态检查和内部安全测试不等同独立第三方安全审计。

历史失败没有被删除或累计到本次结果。2026-09-12 的旧候选曾因 Worker 资源未完整释放失败；2026-09-30 的一次旧检测又因只按 PID 判断进程残留而误报。两项均修复并从零重新计时，本页只引用最终固定输入的完整通过记录。
