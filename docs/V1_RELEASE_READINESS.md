## 本轮实际修复

1. Codex JSONL 改为读取时限长；坏 JSON 不再拼进回答冒充成功，单轮累计回答也有长度限制。
2. 后台 Host 启动异常不再弹出无人确认的模态框；记录错误并以失败码退出。旧候选在相同故障下 5 秒仍未退出，新候选约 0.4 秒退出。
3. 发布扫描拒绝 HashMismatch、NotTrusted 等异常签名；未签名保留明确警告，不伪造可信发行者。
4. 发布工作流在打包前检查同一提交的真实 CI，缺失、失败、未完成、其他提交或其他应用的结果均不算通过。
5. 依赖审查扩展到主分支推送；按用户授权启用仓库 Dependency graph 和 Dependabot 漏洞提醒。没有启用自动合并或发布。
